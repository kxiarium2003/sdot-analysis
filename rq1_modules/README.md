# RQ1 분석 모듈

RQ1("인구집단별 열노출이 거주 기반과 활동 기반에서 얼마나, 어디서, 언제 다른가")의 결과를 보고서(`RQ1 보고 (2026 10 07).md`) 구조 그대로 다시 계산하는 모듈이다. 모듈 이름은 보고서의 절과 가설(H1–H5)에 맞췄고, 모든 모듈은 **집계구 · 행정동 · 자치구** 세 단위로 같은 지표를 낸다.

이 모듈은 이미 만들어진 ΔT 지도와 인구 자료를 입력으로 받아 RQ1 지표를 계산한다. ΔT 지도를 만드는 앞 단계(S-DoT 정리, 기준 기온 크리깅, 집계구 ΔT 모형)는 저장소의 `run_all.sh` 파이프라인에 있다(아래 "입력 자료는 어디서 오나").

## 1. 빠른 시작

```bash
pip install -r requirements.txt            # Python 3.9 기준
python -m rq1_modules.run_rq1              # 전체 (약 1분)
python -m rq1_modules.run_rq1 --threshold  # 30·33°C 초과 노출까지 (약 4분)
python -m rq1_modules.H2_where --scale=dong    # 모듈 하나, 단위 하나
```

- 저장소 최상위 폴더(이 README 의 한 단계 위)에서 실행한다. 모든 경로는 그 폴더 기준이다.
- 결과는 화면에 표로 나오고, `rq1_modules/out/<모듈>.json`에 저장된다.
- `--scale=tract|dong|gu|all`(기본 all)로 단위를 고른다.

## 3. 핵심 정의

| 용어 | 정의 |
| --- | --- |
| ΔT | S-DoT 기온 − 그 자리의 기준 기온(기상청 관측소 66곳을 표고를 고려해 크리깅). 집계구 ΔT 는 12개 도시 형태 변수 회귀로 예측한 (연도 × 계절 × 시각) 평균 |
| 노출 | ΔT × 인구 × 시간. 거주 기준은 인구총조사 인구가 하루 종일 집에 있다고 보고, 활동 기준은 그 시각 생활인구를 쓴다. 두 기준에 같은 ΔT 를 곱한다 |
| 1인당 노출 | Σ 노출 ÷ 서울 인구(°C·시간/년). ÷ 8,760 이면 시간당 평균 °C |
| Gap | 활동 기준 1인당 노출 ÷ 거주 기준 − 1. 생활인구 보정 기준에 따라 부호가 바뀌므로 크기·부호는 주장하지 않는다 |
| 재배치 효과 | Gap 중 "같은 사람이 더 덥거나 덜 더운 곳에 있어서 생긴 몫" = Σ_조건 A·(활동 기준 평균 ΔT − 거주 기준 평균 ΔT). 보정 기준과 무관하다 |
| 생활인구 보정 | 연도·연령마다 기준 시간대(기본 24시간) 평균 재실 인구를 인구총조사 합계(933.5만)에 맞추는 단일 배율. 배율은 모든 집계구로 구한다 |
| 비유사도 | ½ Σ |두 배치의 비중 차이|. 한 배치를 다른 배치로 바꾸려면 최소 몇 %가 옮겨야 하는가 |
| 순위 상관 | 단위를 노출 크기순으로 줄 세웠을 때 두 기준의 순서가 같은 정도(스피어만). 1 = 같음, 0 = 무관 |
| 상위 k% 일치 | 두 기준이 함께 고른 상위 k% 단위의 비율. 무작위면 k%. 자치구는 25개라 상위 5곳(20%)을 쓴다 |
| 16조건 | 2024·2025년 × 계절 4개 × 주야(낮 07–20시, 밤 21–06시) |
| 단위 노출 | 순위·일치 지표: 단위 안 집계구 노출(집계구 ΔT × 인구)의 합 |
| 단위 ΔT | 온도가 들어가는 지표(1인당, 상쇄, 시각별 열 차이, SES, 절대 기온): 행정동·자치구의 ΔT 는 안 집계구 ΔT 의 거주 인구 가중 평균 |
| 집계구 집합 | 노출 지표는 인구총조사에 있는 집계구 19,023개만 쓴다. 인구 수만 비교하는 Q6 와 30·33°C 초과 노출은 19,153개 전부(인구총조사에 없는 130개는 주민 0명) |
| 행정동 | 2016 경계 424개(집계구 코드 앞 7자리). 자치구는 앞 5자리 |

## 4. 결과를 읽을 때 주의할 점

- **생활인구의 집계구 값은 기지국 배분 추정치다.** 기지국 약 6,000곳의 신호를 가중치 모형으로 집계구 19,153개에 나눈다. 새벽 3시에도 인구총조사와의 집계구 순위 상관이 0.28이다(행정동 0.85). 인구총조사와 비교하는 "어디서"는 행정동 단위로 말한다.
- **단위를 키우면 그 안의 이동은 보이지 않는다.** 집계구 값은 동 안의 이동까지 담지만 배분 오차가 섞여 상한에, 행정동 값은 하한에 가깝다. 두 값을 범위로 보고한다.
- **연령별 결과는 내국인 생활인구 기준이다.** 외국인 자료에는 연령이 없다.
- **ΔT 는 실외 기온 기준이다.** 업무지구의 실내 냉방은 반영하지 않는다.
