## 2026-09-07 — measure_time 연도 이상치 1건 발견 (원본 데이터 결함)

- **발견 경위**: 전체 459개 파일 병합(53.1M행) 후 독립 재검증 중, `sdot_2025_v8.parquet`의 날짜 범위가 다른 연도 파일과 달리 2년 넘게 벗어난 것을 확인 → 역추적.
- **원인**: `data/raw/S-DoT_2025/S-DoT_NATURE_2025.08.18-08.24.csv` (2025년 8월 파일) 안에 센서 `V02Q2300002`의 한 행이 `측정시간=2023-11-22_12:07:00`으로 기록되어 있음. 파이프라인 버그가 아니라 **원본 데이터 자체의 결함**(센서 시계 오류로 추정) — 820만 행 중 1건.
- **조치**: 삭제하지 않고 `measure_time_year_outlier` 플래그 컬럼으로 표시(파일이 대표하는 연도에서 ±1년 넘게 벗어나면 True). `scripts/script22-merge-yearly-v8.py`에 이 체크를 추가했고, 기존 산출물 7개 parquet에도 재병합 없이 컬럼만 패치함.
- **전체 스캔 결과**: 53.1M행 전체에서 이 1건 외 연도 이상치 없음.
- **마스터 데이터셋 구축 시 참고**: 이 행을 포함할지 제외할지는 후속 단계(마스터 병합)에서 `measure_time_year_outlier` 컬럼으로 필터링해 결정할 것.

## 2026-09-07 — 위치정보 매핑 누락(고아) 2,373행 조사

- **발견 경위**: `script23`(마스터 병합 + 위치매핑) 결과 독립 재검증 중, `latitude`가 결측인 행 2,373건(전체 53.1M행 중 0.0045%) 확인 → 원인 조사.
- **원인**: 서로 다른 센서 25개의 `sensor_id`가 위치정보 메타데이터 파일(`metadata/서울시 도시데이터 센서(S-DoT) 환경정보 설치 위치정보.xlsx`)에 현재 ID로도, 과거 ID(`변경 전 시리얼` 컬럼)로도 전혀 등재되어 있지 않음 — 파이프라인의 매핑 로직 문제가 아니라 **메타데이터 파일 자체가 해당 센서들을 아직 반영하지 못한 것**.
- **분포**: 상위 10개(`OC3CL200801`~`OC3CL200810`)가 각 ~200건씩, 총 2,020건으로 대부분을 차지. 나머지 15개 센서는 소량. 연도별로는 2025년이 2,020건으로 압도적(나머지는 2020~2023년에 소량 산재).
- **판단**: 특정 소수 센서(25개)에 국한된 문제로, 넓게 퍼진 매핑 오류가 아님. 위치 없는 행은 공간 분석(집계구 일반화 등)에서 자연히 제외되므로 급한 조치는 불필요.
- **후속 조치(선택)**: 메타데이터 파일 갱신본이 확보되면 재매핑 가능한지 확인. 지금 당장 필요한 조치는 아님.
