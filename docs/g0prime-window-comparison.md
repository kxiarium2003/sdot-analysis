# G0′ 기준을 우리 데이터(master-v2)에 적용한 창 비교

작성: 2026-09-21. 스크립트: `scripts/script37-g0prime-window-comparison.py`
(시각별 지표 `data/interim/g0prime_hourly.parquet`, 창별 전체 표 `docs/g0prime-window-candidates.csv`).

**이 문서는 어느 창을 채택할지 결정하지 않습니다.** 결정에 필요한 숫자만 제시합니다.

## 1. 기존 G0′와 여기서 쓴 정의

기존 정리: G0(연속 24개월)를 "네트워크 전체가 한 시간도 안 빠진 연속 24개월"로 재실측하니 최장 4.83개월이라
G0′ = "시간별 완결도 ≥95% + 시간별 보고센서 ≥300대가 창의 90% 이상"으로 재정의, 2023-10-01~2025-09-30
창(완결도 97.8%) 채택.

기존 "완결도" 분모 정의를 그대로 재현할 수 없어 아래처럼 **직접 정의**했습니다. 숫자를 인용할 때 이 정의를 함께 써야 합니다.

| 항목 | 정의 |
| --- | --- |
| 시각 | `measure_time`을 정시로 내림. `measure_time_year_outlier` 행 제외 |
| 보고 센서 n(h) | 그 시각에 기온이 유효(결측 아님, [−25, 45]°C)한 서로 다른 센서 수 |
| 기대 센서 E(h) | 센서 활동기간(그 센서의 최초~최후 기온 유효 시각, script26의 관측기간 개념) 안에 h가 들어가는 센서 수 |
| 센서 집합 | **ALL**: 기온 유효값이 한 번이라도 있는 1,185대 / **NORMAL**: 센서 등급표 '정상' 469대 |
| 시간별 완결도 c(h) | n(h) ÷ E(h) |
| h의 G0′ 충족 | c(h) ≥ 0.95 **그리고** n(h) ≥ 300 |
| 창 | 달력월 시작 기준 24개월(자료 끝 2026-08-30 23:00에서 잘림). 창 충족 비율 = 충족 시각 ÷ 창 시간수. **≥ 0.90이면 G0′ 통과** |
| 네트워크 발행률(R1) | 어떤 센서든 그 시각에 행이 하나라도 있는 시각의 비율 (기존 정리의 "미발행 시간 540시간(3.1%)" 서술과 대응) |

## 2. 지정한 세 창의 수치

| 지표 | 기존 채택 창<br>2023-10-01~2025-09-30 | 우리 분석범위<br>2024-09-01~2026-08-30 | 기존 2년 자료<br>2024-01-01~2025-12-31 |
| --- | --- | --- | --- |
| 시간 수 | 17,544 | 17,496 | 17,544 |
| **G0′ 충족 비율 — ALL** | 0.0% | 0.17% | 0.0% |
| **G0′ 충족 비율 — NORMAL** | 62.8% | 60.5% | 63.7% |
| 보고센서 ≥300대 시각 비율 — ALL | 90.6% | 97.8% | 95.5% |
| 보고센서 ≥300대 시각 비율 — NORMAL | 85.8% | 93.0% | 90.4% |
| 완결도 ≥95% 시각 비율 — ALL / NORMAL | 0.0% / 62.8% | 0.17% / 60.5% | 0.0% / 63.7% |
| 평균 완결도 — ALL / NORMAL | 0.702 / 0.845 | 0.776 / 0.904 | 0.739 / 0.888 |
| 보고센서 중앙값 — ALL / NORMAL | 897 / 429 | 882 / 417 | 898 / 430 |
| 네트워크 발행률(R1) | **92.0%** (빈 시간 1,409) | **97.9%** (빈 시간 374) | **96.9%** (빈 시간 539) |

- **문자 그대로의 G0′(c ≥ 0.95 & n ≥ 300이 창의 90% 이상)는 이 세 창 모두, 어느 센서 집합으로도 통과하지 못했습니다**(최고 NORMAL 63.7%).
- ALL에서 c(h) ≥ 0.95가 거의 성립하지 않는 것은 분모 E(h)에 활동기간 안에서 자주 끊기는 센서(등급 의심·불량 포함)가 다수 들어가기 때문입니다. **분모를 무엇으로 정의하느냐에 따라 결과가 크게 달라지는** 지표입니다(ALL 0~0.2% ↔ NORMAL 60~64%).

## 3. 기존 수치와의 대조 (같은 창인데 우리 쪽이 다르게 나온 이유)

| 항목 | 기존 | 우리(master-v2) | 판정 |
| --- | --- | --- | --- |
| 2024-01~2025-12 어떤 센서도 행이 없는 시간 | 540시간 (3.1%) | **539시간** (3.07%) | 사실상 일치 |
| 2023-10~2025-09 창의 네트워크 발행률 | 97.8% | **92.0%** | 불일치 |

불일치는 표본 구성 차이가 아니라 **2023-10~2023-12에 몰려 있습니다.**

- 이 창의 빈 시간 1,409개 중 **2023-10~12 석 달이 1,116개**, 나머지 21개월(2024-01~2025-09)은 293개(1.91%)입니다. 2023-10~12를 빼면 발행률이 98.1%로 기존 수치와 같은 수준입니다.
- 2023년은 모든 달이 39~64%(288~475시간)씩 비어 있고, **비는 시각이 0시와 13~23시로 정확히 일정**합니다(2023년 빈 시간의 시각 분포: 0시 358, 13~23시 각 357, 그 외 시각은 각 11~15). 하루 12시간이 통째로 없는 패턴입니다.
- 이는 `docs/data-source-notes.md` 2026-09-08 항목의 **v2023_onward 측정시간 12시간(AM/PM) 접힘**(미해결)이 시각별 집계에 남긴 흔적으로 보입니다. 센서 집합(ALL 1,185대)은 기존 정리의 1,086대보다 넓기 때문에, 표본 구성 차이로는 "어떤 센서든 행이 있는 시각" 비율이 이렇게 내려갈 수 없습니다.
- 따라서 **master-v2 기준으로 2022-12~2023-12를 포함하는 창의 시간별 지표는 신뢰하기 어렵습니다.** 2024-01 이후만 보면 기존 수치와 일치합니다.
- 그 밖에 월 단위로 빈 시간 비율이 높은 달: 2022-03 22.6%, 2022-04 16.7%, 2022-08 13.8%, 2022-12 34.1%, 2024-02 16.5%, 2024-12 9.7%, 2025-10 29.0%. 2025-10(216시간)은 우리 분석범위 창에도 포함됩니다.

## 5. 해석할 때의 주의 (결론이 아님)

1. 위 순위는 분모(활동기간 기준 기대 센서 수), 기온 유효 기준([−25, 45]°C), 센서 집합(ALL/NORMAL) 선택에 민감합니다. 기존 정의를 알 수 있으면 같은 정의로 재계산할 수 있도록 스크립트에 상수로 분리해 두었습니다.
2. master-v2의 12시간 접힘이 미해결이라 2022-12~2023-12를 포함하는 창의 수치에는 접힘 아티팩트가 섞여 있습니다. v3(수정본) 마스터가 나오면 이 스크립트를 v3에 그대로 재실행해 비교해야 합니다.
3. 2020~2021 시작 창이 (a)에서 높게 나오는 데에는 시기별 활동 센서 수(분모) 변화의 효과가 섞여 있을 수 있으나, 이번 계산에서는 그 효과를 분리해 확인하지 않았습니다.
4. 이 문서는 G0/G0′ 중 무엇을 채택할지, 연구 창을 어떻게 잡을지에 대한 판단을 포함하지 않습니다.
