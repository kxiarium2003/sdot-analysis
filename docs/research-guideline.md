## 0. 연구 개요

### 0.1 한 문장

거주지 기준으로 계산한 열노출과 실존 인구(생활인구) 기준으로 계산한 열노출의 차이(Gap)를 서울 전역에서 정량화하고, 그 차이가 무더위쉼터 배치 평가를 어떻게 바꾸는지 감사한다.

### 0.2 연구 질문

- RQ1: 인구집단(연령 × 거주지 SES)별 열노출은 거주 기반과 활동 기반으로 계산할 때 얼마나, 어디서, 어느 시간대에 다른가
- RQ2: 무더위쉼터 커버리지는 두 기준으로 평가할 때 얼마나 다르며, 동적 기준에서 드러나는 커버리지 공백은 어디인가
- RQ3: 쉼터 재배치를 최적화할 때, 수요 정의(거주 인구 / 생활인구 / 생활인구×이상장)에 따라 최적 입지와 달성 커버리지는 얼마나 달라지는가

### 0.3 기존 연구와의 차별

1. 기존 열 형평성 연구는 거주지 온도(대부분 위성 LST, 주간 표면온도)를 노출로 정의한다
→ 위성으로 찍은 지표면 온도(LST, 주로 낮에 찍음)를 쓰고, 인구는 거주지 기준(센서스)만 씀 
→ 즉 온도도 사람도 둘 다 "정적”
2. 유동인구 + 정수계획으로 무더위쉼터 입지를 최적화한 선행 연구가 존재한다(울산 대상, Urban Climate 2021; location routing 후속 2022). 반드시 인용하고 다음과 같이 차별화한다: 해당 연구는 수요(인구)는 동적이지만 위험(온도)은 도시 단위 지수로 공간 균일하며, 최적화로 직행할 뿐 평가 기준 자체를 감사하지 않는다
→ 사람은 유동인구로 동적으로 추적했지만, 온도는 THI라는 도시 전체에 딱 하나의 숫자(도시 전체가 똑같이 덥다고 가정)
→ 
- 본 연구는 
(a) 야간 포함 초국지 기온 이상장과 
(b) 시간별·연령별 실존 인구를 결합해 노출을 재정의하고, 
(c) 그 재정의가 현행 배치의 평가(RQ2)와 미래 배치의 처방(RQ3)을 모두 바꾸는지 검증한다
- 서울 생활인구는 집계구 × 시간 × 연령 해상도의 실존 인구 공공데이터로, 이 해상도를 공개하는 도시는 드물다

### 0.4 논문 구조 (그림 4장)

1. 야간 초국지 이상장 지도
2. 집단별 노출: 거주 기반 vs 활동 기반, Gap 지도
3. Gap의 시간 구조 (주간/야간 분리)
4. 쉼터 커버리지: 두 기준 비교 + 공백 지도
5. 최적 입지의 수요 정의별 발산: 3×3 교차 평가 행렬 + 발산 지도

## 2. Phase 0 — S-DoT 감사와 병합

공개 센서 데이터는 발행 단계에서 조용히 손상돼 있을 수 있다. 병합 전 전수 감사한다.

1. 파일 인벤토리: 경로, 패턴, 행수, 헤더, 인코딩(헤더 행 기준 판별), 구분자
2. 스키마 클러스터링: 헤더 컬럼 집합 기준. 연도로 분기하지 않는다
3. 시각 손상 확인: 지수표기 파괴(복구 불가), 12시간제 접힘(조합당 2행 + 00시 부재), 비표준 구분자
4. 병합 불변식: 모든 파일은 수용 또는 사유 있는 거부. `수용 + 거부 = 전체` 미성립 시 에러 중단. 파일별 행수 감사. 기간 필터 금지. 0 치환 금지
5. 센서 진단: 커버리지(분모는 기대 관측수), 물리 범위 [−25, 45]°C, 고착 판정 → 센서 등급표

게이트 G0: 시각이 온전한 연속 구간 24개월 이상. 미달 시 보고.

산출물: `phase0/merged/`, `merge_audit.csv`, `sensor_health.csv`

## 3. Phase 1 — 참조장과 이상장

1. 크리깅: 표고 외부 표류 KED. IDW 금지. 배리오그램 월별 적합
- **크리깅 Kriging:** 센서 없는 곳의 온도를 추정하는 통계 기법
    - 주변 센서값들을 거리에 따라 가중평균해서 빈 곳을 채우는 방법
    - 여기서는 "KED(외부 표류 크리깅)"라는 버전 씀.
    → 단순 거리만 보는 게 아니라 표고(고도)도 같이 참고해서 채움
    - 산 위는 낮은 지역보다 시원한 경향이 있으니까, 그 정보를 보정에 반영
    - IDW(역거리가중법) 금지
    : IDW는 표고 같은 보조정보를 못 쓰는 더 단순한 방법이라 여기선 안 쓰겠다는 뜻
1. 검증: AWS LOOCV(주/야·계절별 RMSE), ASOS 종로 홀드아웃(크리깅 미포함)
2. 이상장 정의: $ΔT_it = T^SDOT − T̂^KMA = (S-DoT 실측값)-(참조장 예측값)$
3. 표본(사전등록): 정상 등급 + 커버리지 ≥ 0.5 + ΔT 중앙값 [−10, +10]°C
4. 기술통계: 시간 평균 지도의 공간 타당성(고밀 양, 산림 음), 주/야 분리(야간이 커야 정상)
- 게이트 G1: $LOOCV RMSE ≤ 1.0°C$$(야간), 1.5°C(주간)$
- 게이트 G2: 표본 ≥ 300대, 야간 이상의 공간 SD ≥ 0.5°C

산출물: `phase1/anomaly_panel.parquet`

## 4. Phase 2 — 이상장의 집계구 일반화

노출 회계는 집계구 단위이므로 센서 지점 ΔT를 전 집계구로 일반화한다. 모형은 도구다 — 잘 검증된 것 하나면 충분하다.

1. 변수: 집계구 기준 건폐율, 녹지·불투수면 비율, 건물 높이, 표고, 도로 밀도 (버퍼 250m 기본, 100/500m은 강건성)
2. 타깃: 센서별 (a) canonical 야간 이상(맑음·저풍속 밤 평균), (b) 주간 이상, (c) 여름 야간 이상
3. 모형: XGBoost 기본. 선형(OLS) 대비 개선을 확인하고, 개선 없으면 OLS 사용. GNN 등 추가 비교는 하지 않는다
4. 평가: 시간 기반 분할(test는 한 번만) + 공간 블록 CV(자치구 블록) 병행. 랜덤 CV 단독 평가 금지
5. 불확실성: 앙상블 분산 또는 컨포멀 예측으로 집계구별 예측 구간 산출. 이후 모든 수치에 전파
6. 검증 지도: 센서 보유 집계구에서 예측 vs 관측. 체계적 편향 시 보고

**게이트 G3:** 공간 블록 CV에서 예측 오차가 야간 이상의 공간 SD보다 작아야 한다(신호 > 오차). 미달 시 일반화를 포기하고 센서 보유 집계구만으로 분석 범위를 축소한다 — 이것도 유효한 설계다.

산출물: `phase2/anomaly_by_zone.parquet` (집계구 × 프로파일 × 구간)

## 5. Phase 3 — 노출 회계 (본론 1)

### 5.1 생활인구 전처리

- 경계 매핑 적용, 매핑 불가 집계구는 사유 기록 후 제외
- 이상값(전주 대비 급변)은 플래그만, 치환 금지
- 집단 정의: $연령 {0–14, 15–64, 65+} × 거주지 SES 분위(SGIS)$. 개인 SES가 아니라 거주지 SES임을 명시

### 5.2 두 가지 노출 (사전등록)

활동 기반:
$E_g^A = Σ_t Σ_s ΔT_{s,t} · Pop^{생활}_{g,s,t}$

거주 기반 (기존 문헌의 정의):
$E_g^R = Σ_t Σ_s ΔT_{s,t} · Pop^{거주}_{g,s}$

- $ΔT_{s,t}$: Phase 2 프로파일을 시각 조건(주/야·계절)에 매핑
- 절대 임계 버전 병행: $T̂^KMA + ΔT$ 로 기온을 복원해 30°C 초과 인시 산출
- 단위: 집단별 1인당 인시. 야간(21–06시, 열대야) 분리 필수
- 모든 수치는 Phase 2 불확실성 구간과 함께 보고

### 5.3 Gap 산출 (RQ1의 답)

$Gap_g = E_g^A − E_g^R$

- 집단별 Gap 표와 지도 (어느 집계구에서 활동 노출이 거주 노출을 초과하는가)
- 주간/야간 분리: 주간은 통근이 노출을 재배분하고 야간은 거주지로 수렴할 것으로 예상되나, 예상은 전제가 아니다
- 형평 지표: 집단별 노출의 집중지수, 상·하위 SES 분위 비 — 두 기준 각각 산출해 비교

게이트 G4: 두 기준의 집계구 순위 상관이 0.98 초과이고 Gap이 불확실성 구간 안이면, 동적 회계가 정보를 더하지 않는 것이다. RQ2를 거주 기반으로 수행하고 논문을 “거주 기반 회계의 타당성 검증”으로 재구성한다. 억지로 차이를 만들지 않는다.

산출물: `phase3/exposure_ledger.parquet`, Gap 지도

## 6. Phase 4 — 무더위쉼터 감사 (본론 2)

### 6.1 접근성

- 도보 네트워크 기반 최근접 쉼터 도보 시간 (직선거리 금지)
- 커버 정의(사전등록): 도보 10분 이내 + 해당 시각 운영 중

### 6.2 커버리지 감사 (RQ2의 답)

고령(65+) 집단에 대해:

- 거주 기준: 고령 거주 인구 중 커버 비율 — 현행 배치가 암묵적으로 최적화한 기준
- 동적 기준: 고령 열노출 인시(폭염일 33°C 초과, ΔT 상위 구간) 중 커버 시간·공간 안에서 발생한 비율
- 야간 분리: 열대야 시간대 운영 쉼터만으로 재계산. 야간 공백이 예상 지점이다
- 산출: 두 기준의 커버리지 차이, 공백 지도(동적 기준에서만 드러나는 미커버 노출 밀집지), 공백 상위 지역 목록

산출물: `phase4/shelter_audit.md`, 공백 지도

## 6b. Phase 4b — 재배치 최적화: 수요 정의 비교 실험 (RQ3, 본론 3)

최적화 도구의 시연이 아니라, 수요 정의가 최적해를 바꾸는지에 대한 비교 실험이다. 유동인구 기반 쉼터 최적화 자체는 선행 연구(울산)가 있으므로, 기여는 “무엇으로 수요를 재느냐에 따라 답이 달라진다”의 정량화에 있다.

### 6b.1 세 가지 문제 (사전등록)

동일한 MCLP(maximal covering location problem)를 수요 정의만 바꿔 세 번 푼다.

| 문제 | 수요 w_s | 의미 |
| --- | --- | --- |
| $P_R$ | 고령 거주 인구 (census) | 기존 배치 관행
→ 지금까지 정부가 쉼터 배치할 때 암묵적으로 쓰던 기준 |
| $P_A$ | 고령 생활인구 (폭염일 시간 평균) | 선행 연구(울산) 방식
→ 유동인구로 배치 |
| $P_{AT}$ | 고령 생활인구 × ΔT 가중 인시 | 본 연구의 완전 정보
→ Phase 3에서 계산한 진짜 노출량까지 반영 |

공통 설정:
- 후보지: 기존 쉼터 전체 + 신규 후보(공공시설 목록: 주민센터, 도서관, 복지관 등)
- 결정: 신규 K개 추가 지정 (K = 50 기본, 25/100 민감도)
- 커버: 도보 10분 이내 + 운영 시간 내
- 목적함수: 커버되는 수요의 최대화
- 형평 제약: SES 하위 분위 집계구의 커버리지 하한 (제약 유/무 두 버전)
- 솔버: 정수계획 (OR-Tools 또는 Gurobi). 휴리스틱 사용 시 최적성 Gap을 보고

### 6b.2 비교 지표 (논문의 답)

1. 입지 중첩: 세 해의 선정 지점 간 Jaccard 유사도. 세 답이 실제로 다른가
2. 교차 평가(후회): $P_R$의 해를 $P_{AT}$의 기준으로 평가했을 때 달성하는 커버리지 / $P_{AT}$ 해의 커버리지. 이 비율이 낮을수록 관행 기준 배치가 취약 노출을 놓친다
    - 교차 평가 행렬 3×3 전체를 보고한다 (어느 기준으로 뽑고 어느 기준으로 평가하는가)
3. 공간 발산 지도: $P_{AT}$에서만 선정되는 지점들의 위치와 특성 (야간 열대야 밀집지, 시장·공단 인접 등)

게이트 G5: 세 해의 Jaccard가 모두 0.9 초과이고 교차 평가 손실이 5% 미만이면, 수요 정의가 입지 결정에 실질적 영향을 주지 않는 것이다. RQ3를 “관행 기준의 강건성 확인”으로 재구성한다. 억지로 차이를 만들지 않는다.
