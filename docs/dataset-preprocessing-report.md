### Guideline 기준 (원문)

> 시각 손상 확인: 지수표기 파괴(복구 불가), 12시간제 접힘(조합당 2행 + 00시 부재), 비표준 구분자
> 병합 불변식: 모든 파일은 수용 또는 사유 있는 거부. `수용 + 거부 = 전체` 미성립 시 에러 중단. 파일별 행수 감사. 기간 필터 금지. 0 치환 금지
> 센서 진단: 커버리지(분모는 기대 관측수), 물리 범위 [−25, 45]°C, 고착 판정 → 센서 등급표
> 표본(사전등록): 정상 등급 + 커버리지 ≥ 0.5 + ΔT 중앙값 [−10, +10]°C
> 게이트 G0: 시각이 온전한 연속 구간 24개월 이상. 미달 시 보고.

| 항목 | 현황 | 근거 |
| --- | --- | --- |
| 지수표기 파괴 | ✅ | 등록일자 폴백 (`script22`) |
| 12시간제 접힘 | ❌ | 조사만 완료, 수정 스크립트 없음 |
| 비표준 날짜 구분자 | ✅ | 4포맷 정규화 (`script22`) |

| 병합 불변식 | ✅ | `script22` assert. 단 거부 건수는 `.done`에 기록되지 않고 실행 로그에만 출력. 2026-09-07 감사의 "미구현"은 `script16`(구버전) 기준이라 현행과 다름 |
| 센서 진단 | ✅ | `script26` |
| 표본 기준 | 🟡 | `script31`은 **정상 등급만** 적용. ΔT 중앙값 [−10,+10] 필터는 코드에 없으나, 현재 표본 453대의 중앙값이 −0.19~+3.51°C라 적용해도 제외 0대 |
| G0 | 🟡 | 2020-04~2026-07 76개월 연속(결측 월 0)이나, 2026-09-07 시점 1회성 정규화 코드에 의존해 재현 가능한 검증으로 고정돼 있지 않음 |

### 확인 사항 · 한계

- v3(12시간 접힘 수정본) 마스터가 없어 Phase 1은 v2 마스터로 진행 (연구자 확인). v3가 나오면 재실행해 비교 필요.
- 센서 등급은 센서 **자신의 활동기간** 기준이라 분석기간과 겹치는지는 보지 않음. 449(센서→집계구 매핑) → 453(분석기간 유효 센서) → 441(집계구) 차이가 이 때문에 발생했고 파이프라인 버그는 아님.
- 2024-09~2026-08 구간의 12시간 접힘 잔존분은 위 3,096개 충돌 그룹 제외로 대응했을 뿐, 근본 수정은 아님.

- 수집 도중 2024-08~2024-11 4개월이 한때 0행이었고 2022-03/04, 2024-07도 부분 유실됐으나 재수집으로 복구.

| 컬럼 타입이 날짜마다 다르게 추론 (정수 vs 실수) | 장기체류외국인 2025-09 등 | 인구수 컬럼을 `float64`로 고정 |
| 헤더만 있고 데이터 0행인 날짜 | 내국인 2026-05-02, 05-04~05-09 (7일) / 장기체류외국인 2025-07-08, 07-09 (2일) | 변환 건너뜀. **해당 날짜는 D5 값 없음** |

### Guideline 기준 (원문)

> 집계구 경계는 연도에 따라 바뀐다. 경계 변경 매핑 테이블을 먼저 만든다
> 통신 기반 추정치임을 논문에 명시한다
> 연령 구간 등 컬럼 구성이 기간에 따라 바뀌었는지 확인한다
> 서울 전체 합의 일별 시계열로 단절(보정계수 변경 등)을 확인한다
> 경계 매핑 적용, 매핑 불가 집계구는 사유 기록 후 제외
> 이상값(전주 대비 급변)은 플래그만, 치환 금지
> 집단 정의: 연령 {0–14, 15–64, 65+} × 거주지 SES 분위(SGIS). 개인 SES가 아니라 거주지 SES임을 명시

| 항목 | 현황 | 근거 |
| --- | --- | --- |
| 경계 매핑 테이블 | ✅ | 2016→2025 크로스워크 (D9 참고) |
| 매핑 불가 집계구 사유 기록 | ❌ | 크로스워크 미매칭 1건, 그리고 E^A 산출 집계구가 14,868개로 19,092개보다 적은 이유 모두 **원인 미조사** |
| 연령 구간·컬럼 구성 변화 확인 | 기록 없음 | 한 달 안 일별 파일 헤더가 같음은 확인했으나 23개월 간 비교 기록 없음 |
| 서울 전체 일별 합 단절 확인 | 기록 없음 | |
| **이상값(전주 대비 급변) 플래그** | ❌ | 코드베이스에 구현 없음 (`script30`은 변환만) |
| 집단 정의 (연령 × SES) | ❌ | Phase 3는 **총인구만** 사용 (연령·SES 미분해) |

### 미해결

- 노출지표 정의 `exposure_contribution = 인구 × ΔT_zone`이 아직 제안 단계 (사전등록 확정 아님).
- D5 컬럼 구성이 기간에 따라 바뀌었는지, 일별 총량에 단절이 있는지 확인 필요.
