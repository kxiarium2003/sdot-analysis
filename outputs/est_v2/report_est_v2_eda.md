# 65+ 버스 승하차 추정 v2 EDA: 분모 구축, 실현 가능성, 지하철 검증

작성 2026-11-09. 표기: **[확인됨]** 파일을 직접 계산해 확인 · **[추정]** 근거는 있으나 직접 검증하지 않음 · **[미확인]** 확인하지 못함

## 요약

- 분모: D25로 만든 정류장×날짜×시간 승차·하차는 D15와 거의 같다. 서울 전체 차이는 승차 −0.10~+0.01%, 하차 −0.03~+0.08%다 [확인됨].
- 하차 시각: H1은 D16보다 평균 약 7~8분 이르고, H2는 D16과 일치한다 [확인됨]. H2 일치는 D16 분포로 나눈 결과이므로 당연하다 [확인됨: 구성].
- P1(OD 매칭)과 P2(주변 생활인구)는 역×월에서는 비슷하지만, 시간대가 들어가면 P1이 크게 앞선다 [확인됨].
- 이 검증은 지하철 D26 기준이다. 버스에서 같은 성능이 나오는지는 [미확인]이다.

## 입력과 실행

- 원자료는 스크래치에 내려받아 썼고 작업 후 지웠다 [확인됨]. 다시 받을 때는 `s00b_fetch_raw.sh`를 쓴다.
- 실행 순서: s00b → s01 → s02 → s03 → s03b → s04 → s05 → s06 → s07 → s08 → s09(`station_month,station_hour`) → s09(`cell`) → s10. 환경변수 `EST_V2_SCRATCH` 필요.
- D17·D18은 metadata 파일이 없어 `outputs/eda_bus65/report_bus65_estimation.md`와 원본 파일로 확인했다 [확인됨]. D12·D5는 `docs/data-source-notes.md`로 확인했다 [확인됨].
- 그림은 dataviz 기본 팔레트 1~3번 슬롯을 썼다. 이 환경에 node가 없어 팔레트 검증 스크립트는 실행하지 못했고, 문서에 적힌 전 쌍 검증값을 따랐다 [미확인: 재검증].

## A. Step 1 분모

### 하차 ID 결측 처리

- 버스 승차 행의 하차 ID 값은 9자리, 빈칸, `-`다. 4자리 하차는 없다 [확인됨].
- 처리: 결측 행은 **승차에만 포함**하고 하차에서는 뺀다. 대상 정류장 승차 중 결측 비중은 1.98~2.07%다 [확인됨]. 하차가 대상 밖인 비중은 1.73~1.97%다 [확인됨].
- 이 처리로 D25 승차와 D15 승차, D25 하차와 D15 하차가 각각 맞는다(아래) [확인됨]. D15 하차도 하차 태그가 없는 승객을 세지 않는 것으로 보인다 [추정].

### C-1. 평가 설정

- 실제값: D26 노인 승차 / D18 전체 승차. 역×날짜×시간(06~24시), 06시 이전·24시 이후 제외 [확인됨]. 전체 비율 14.07% [확인됨].
- P0: 자치구 D12 65+ 출발 이동 비율(요일×시). 도착 시각에서 이동 시간을 뺀 출발 시각 기준 [확인됨].
- P1: D25 역→역 OD × D12 동 쌍 65+ 비율 (요일×출발시 기준). `P1ns`는 도착 시각 그대로 쓴 민감도. 마스킹 0/3 각각 [확인됨].
- P2: 역 반경 300·500m 집계구 D5 65+ 비중(날짜×시). 반경 안에 중심점이 없는 역(300m 5개, 500m 1개)은 교차 집계구 사용 [확인됨]. 마스킹 0(기본)/3 민감도 [확인됨].
- 공통 표본: 모든 예측이 있는 칸 561,138칸, 121일, 258역 [확인됨]. D25 결측 3일은 P1이 없어 빠진다 [확인됨]. ③은 칸 승차 10명 이상(560,621칸) [확인됨].
- P1 커버리지: 역 승차 중 도착 역이 서울인 것 85.5%, D12 칸까지 맞는 것 77.7% [확인됨]. 서울 밖 도착은 행정동을 알 수 없어 뺐다 [확인됨].
- 실제 로짓은 경험 로짓, 예측 로짓은 0.001~0.999로 자름 [확인됨].

## P1 vs P2 판단

- 역×월에서는 둘이 사실상 같다. CV R² 0.692(P1 m3) 대 0.679(P2 300m), 2024→2025 이전 R² 0.695 대 0.701이다 [확인됨]. 역 간 수준 차이는 주변 인구 구성으로도 설명된다 [추정].
- 시간대가 들어가면 P1이 크게 앞선다. ② CV R² 0.764 대 0.290, ③ 0.597 대 0.254 [확인됨]. P2는 생활인구 구성의 시간 변화가 작아 시간대 차이를 만들지 못한다 [추정].
- 목표가 날짜×시간 값이므로 **P1을 추천한다** [추정]. 최종 선택은 사용자 몫이다.
- P1의 단서:
  - 도착 시각 → 출발 시각 변환이 성능을 높인다 [확인됨].
  - 마스킹 3이 0보다 조금 낫지만 차이는 작다 [확인됨].
  - 지하철 승차의 14.5%는 서울 밖 도착이라 쓰지 못했다 [확인됨]. 버스는 대상 밖 하차 1.7~2.0%, 하차 결측 2%로 커버리지는 더 낫다 [확인됨].
  - 시간대별 P0(자치구)도 ③에서 순위 상관 0.74로 꽤 높다. ③의 성능 상당 부분은 시간대·요일 패턴에서 온다 [추정].
  - D12는 이동 수단을 구분하지 않는다. 버스 이용자의 연령 구성이 일반 이동과 다르면 수준이 어긋날 수 있다 [추정]. Step 3 보정이 필요하다.

## 결정이 필요한 사항

1. **Step 2 방법:** P1(추천) 또는 P2.
2. **하차 시각:** H1(날짜별 변화 유지, D16보다 7~8분 이름) 또는 H2(D16과 일치, 날짜별 시간 변화 없음).
3. **P1 마스킹 값:** 0, 3, 또는 범위를 유지할지. 버스 OD의 94%에 마스킹이 있어 범위 폭은 동 쌍 중앙값 0.021이다.
4. **출발 시각 변환:** 행별 이동 시간으로 도착 → 출발 변환(3시간에서 자름)을 채택할지.
5. **서울 밖 도착:** P1에서 뺄지, 출발 동 기준 비율로 대체할지. 지하철 14.5%, 버스 1.7~2.0%다.
6. **같은 동 안 버스 이동 17%:** D12 비율을 그대로 쓸지, 도보 오염으로 보고 처리할지.
7. **2024-08-20:** D25 그대로 쓸지, 결측일처럼 D15·D16으로 대체할지. D25가 D15보다 2.8% 적다.
8. **정류장 13개**(동 미배정)와, P2를 쓸 경우 300m 안에 중심점 없는 정류장 316~325개 처리.
