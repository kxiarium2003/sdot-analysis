# 65+ 버스 승하차 추정(단순판)과 폭염 쉼터 커버리지·배치 baseline

작성 2026-11-09. 표기: **[확인됨]** 파일을 직접 계산해 확인 · **[추정]** 근거는 있으나 직접 검증하지 않음 · **[미확인]** 확인하지 못함. 대상 월 202407, 202408, 202507, 202508.

## 미팅용 요약

1. D12 서울 생활이동 OD 매칭(P1)에 지하철 보정(m3: a=-0.247, b=0.944, 공간 CV R² 0.597)과 노인실태조사 규모 맞춤(월별 k 1.06~1.16)을 적용하면, 서울 버스 65+ 승차는 월 29.7~32.0백만 명, 승차의 22.0~22.9%다 [추정]. 지하철 보정이 버스에도 맞는지는 [미확인]이다.
2. 2025년 11~17시 65+ 승차의 88.5%가 스마트쉼터 정류장 또는 무더위쉼터 300m 안에 있고, 11.5%(정류장 1,512개)가 커버 밖이다 [추정]. 300m 대신 150m면 50.3%, 500m면 98.1%로 크게 달라진다 [확인됨: 계산].
3. 스마트쉼터 100개(O2)는 커버 밖 65+ 승차의 45.1%, 무더위쉼터 30개(O3, 정류장 위치 대용)는 44.5%를 새로 커버한다 [추정].
4. 65+ 대신 총 승차로 뽑으면 O2 p=100 겹침 80개(Jaccard 0.67), 65+ 커버는 871명 줄어든다 [추정]. 선택은 m0·m3 범위에는 안정적이고(Jaccard 0.82 이상) 반경(최대 0.16)과 연도(최대 0.27)에는 민감하다 [확인됨: 계산].
5. 스마트쉼터는 D14 폭염저감시설 199행 중 ARS가 있는 141행(70.9%)만 연결돼 (a)는 하한이다 [확인됨]. 정수계획 검증은 pulp·ortools가 없어 건너뛰었다 [확인됨].
